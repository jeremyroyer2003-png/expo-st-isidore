# Expo St-Isidore : application Next.js

```bash
npm install
cp .env.example .env.local
npm run dev        # http://localhost:3000
npm run verifier   # typecheck + lint + build
```

Mode test seulement (Stripe test, courriels simulés). Aucun déploiement avant l'approbation du comité.
