# Démarrer dans Claude Code

1. Décompresse ce dossier quelque part sur ton ordinateur, par exemple `Documents/expo-st-isidore`.
2. Ouvre un terminal dans ce dossier (ou ouvre le dossier dans VS Code avec l'extension Claude Code).
3. Lance `claude`.
4. Colle ce premier message :

> Lis CLAUDE.md et ouvre maquettes/accueil-v2.html pour voir la direction visuelle. Ensuite, propose-moi la structure du projet (dossiers, fichiers, choix entre HTML simple et Astro) avant d'écrire du code. Une fois que je valide, construis seulement la page d'accueil, puis montre-moi des captures sur ordinateur et sur téléphone.

5. Valide chaque page avant de passer à la suivante.

## Contenu du dossier

- `CLAUDE.md` : le résumé de tout ce qui a été décidé. Claude Code le lit tout seul.
- `maquettes/` : les maquettes en HTML (accueil v1 et v2, remisage), avec images et polices. Ouvre-les dans ton navigateur.
- `recherche/` : l'histoire de l'Expo, les bâtisseurs, les activités disparues et le journal de 2010.
- `images-sources/` : d'autres découpes de photos de l'ancien site.
